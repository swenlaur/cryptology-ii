\begin{exercise}{Existence of perfect message auhtentication codes}
A deterministic message authentication code  $h:\KSPACE\times\MSPACE\to\TSPACE$ is perfect if the success of impersonation and substitution attaks is bounded by 
$\smash{\frac{1}{\abs{T}}}$ and $\abs{\KSPACE}=\abs{\TSPACE}\cdot\abs{\TSPACE}$. It is easy to construct such codes for $\abs{\KSPACE}=\abs{\MSPACE}\cdot\abs{\MSPACE}$ but it is  harder for longer messages.
Construct a perfect mesasage authentication code $h:\ZZ_2^2\times\ZZ_2^2\to\ZZ_2$ or prove that no such codes can exist. 
\end{exercise}
